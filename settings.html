Settings

Configure branding, colors, telephony, and API endpoint for the SAV package system.

API endpoint

If left blank, the system uses the current host on port 5000 (for example http://192.168.1.50:5000/api). Enter a full URL to use a hosted server instead.

Public tracking page

Customize the public tracking page appearance.

Shown under your logo on the customer lookup screen.

If left empty, the existing logo is kept.

Colors

Color configuration (text, backgrounds, staff bar) can be added here in future. Current version uses default theme.

Telephony (Grandstream)

Configure automated pickup calls via Grandstream UCM6302A.

These settings control automatic calls to customers when packages are processed.
